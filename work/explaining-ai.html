AI Education / Technical Translation

If I had to explain AI to a layman, I’d start with a Loss Function

Most educational explainers answer the question of how without first giving the reader the mental model to operate in. I answer what and why before diving into how.

If I had to explain AI/ML/Claude and the whole shebang to a layman, let’s say, a German lawyer, I’d start with a Loss Function and what it means to minimize it.

Usually when non-tech people feel FOMO and want to understand “AI”, they dive straight into neural networks, transformers, watch 3b1b animations etc. and in the end stay confused.

“Self-attention mechanism by matrix multiplication” means to them as much as “transactions are stored in blocks” when they try to understand blockchain - not much. Because you can’t explain abstract ideas to someone who last dealt with abstractions in high school by giving them more abstractions.

That’s why we start small.

Loss Function.

Assume the reader knows what a function is - in simple words, an operator that takes an input and produces an output.

A Loss Function is a function that measures loss. In ML, loss is a numerical measure of how wrong a model’s prediction was compared with the actual value.

A Loss Function is not one defined function like a square root. There are various loss functions for different classes of ML problems.

One of the most well-known ones is MSE - mean squared error. You have probably seen something very similar in a basic statistics class. It is the average of the squared differences between the actual value and the value predicted by the model.

It is one of the standard loss functions used for regression.

Yes, regression is also a machine learning problem.

The task of machine learning is to find a model that makes this loss as small as possible.

Let’s take a stupidly simple example.

We want to predict apartment prices. We have historical data with the size of an apartment and the price it actually sold for, and we build a model that tries to predict the price from the size.

For three apartments, reality looks like this:

Actual prices: €500k, €700k, €900k.

Our model predicts: €550k, €650k, €800k.

So the errors are €50k, -€50k and -€100k.

Here is why MSE is a good loss measure for this case: If we simply averaged these errors, positive and negative errors could cancel each other out and make a terrible model look good. Squaring avoids this.

If we measure the prices in 1k EUR, we get:

(50² + 50² + 100²) / 3 = 5000

We have taken three predictions and reduced “how wrong was the model?” to one number.

Now imagine another model predicts €510k, €690k and €880k.

The errors are 10, -10 and -20.

Its MSE is:

(10² + 10² + 20²) / 3 = 200

A lot smaller loss.

So if we have to choose between these two models based on this loss function, the second model is doing better.

This is what “minimizing the loss” means.

We want the model to make predictions for which the value returned by the loss function is as small as possible.

There is one detail here that I think gets skipped too often in beginner explanations: the loss function is not some universal mathematical definition of being wrong.

We choose it.

A classification model, for example, will usually use a different loss function, such as cross-entropy.

Accuracy, precision, recall etc. are related, but they are evaluation metrics rather than loss functions. We’ll get to that distinction later.

This is why there are many loss functions.

Before there is a neural network, transformer, Claude, GPU or anything else people normally associate with AI, there is a much more basic question:

What are we asking the model to get better at?

Mathematically, it is minimizing the loss function.

It takes the model’s prediction and the actual answer and gives us a number representing how bad that prediction was according to the rule we chose.

High loss - bad, lower loss - better.

Training a machine learning model means trying to make that number smaller.

That’s enough about loss functions for now.
